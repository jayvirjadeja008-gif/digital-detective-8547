# Task 5.4 — How is text stored?

- ASCII decimal code for uppercase `A`: 65
- ASCII decimal code for lowercase `a`: 97

An encoding standard gives every character a consistent numeric representation. Without it, a computer and another computer might interpret the same bytes as different characters.

One character outside basic ASCII is `₹`, the Indian rupee symbol. UTF-8 can encode it, along with many scripts and symbols that basic ASCII cannot represent.
