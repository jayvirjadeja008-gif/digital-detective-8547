## 4. Commands / tools used
- `python3` — opened Python and ran the converter.
- `bin()` — converted integers to binary strings.
- `hex()` — converted integers to hexadecimal strings.
- `int(value, base)` — converted text in binary or hexadecimal form to decimal.
- `input()` — accepted a number from the user.

## 5. My understanding
Binary uses base 2, decimal uses base 10 and hexadecimal uses base 16. Python can verify manual work and convert integers with built-in functions. Encoding standards allow text characters to be represented consistently as bytes.
