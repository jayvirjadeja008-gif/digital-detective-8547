## 4. Commands / tools used

- `dig +short example.com` — performed a DNS lookup.
- Markdown — created the network tables and explanations.

## 5. My understanding
Networks exchange data between devices using addressing, routers and communication protocols. DNS connects readable domain names to IP addresses. When a browser opens a website, it acts as a client and communicates with a server through the network.
