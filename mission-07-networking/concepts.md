# Task 7.1 — Network concepts

| Concept | Explanation | Example |
|---|---|---|
| LAN | A Local Area Network connects devices over a small area such as a home, lab or office. | Wi-Fi devices in a classroom |
| MAN | A Metropolitan Area Network covers a city or a large campus area. | A university network connecting several campus buildings |
| WAN | A Wide Area Network covers large geographical areas and connects multiple smaller networks. | The Internet |
| DNS | DNS translates a domain name such as `example.com` into an IP address that a network can use. | `example.com` resolved to public IP addresses |
| Router | A router forwards data between networks and usually directs traffic toward the Internet. | A home router connects devices to an Internet provider |
| Protocol | A protocol is a shared set of rules that determines how devices format and exchange data. | HTTP/HTTPS controls web communication |
| Packet switching | Packet switching divides data into packets that can be routed across a network and reassembled at the destination. | Web page data split into network packets |
| Client-server | In this model, a client requests a service and a server provides a response. | A browser requests a page from a web server |
