# Task 7.3 — What happens when a website opens?

1. The user enters a website name in the browser, which acts as the client.
2. The browser asks a DNS system to translate the domain name into an IP address.
3. DNS returns one or more server addresses.
4. The browser selects a network route and sends an HTTP or HTTPS request through the computer's network interface and router.
5. Routers and network infrastructure forward the packets toward the destination server using the network protocol rules.
6. The server receives the request and prepares a response containing data such as HTML, images or instructions.
7. The server sends the response back to the client, and the browser processes and displays the page.
