# Task 7.2 — Network observations

Using the public example domain `example.com`:

- `ping -c 2 example.com` sent two connectivity test packets and received two replies. It reported 0% packet loss in this observation.
- `dig +short example.com` returned public DNS address results. Address values are normal public data and are not included in this document.

## Answers

- **What connectivity testing helps check:** It checks whether the computer can send packets to a reachable destination and receive replies.
- **What DNS lookup displays:** It displays one or more network addresses associated with the queried domain name.
- **DNS in a browser:** When a website name is entered, DNS translates the domain name into an IP address that the browser can use to contact the appropriate server.
