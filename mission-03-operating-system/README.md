## 4. Commands / tools used
- `sw_vers` — checked operating-system details.
- `df -h /` — checked root storage usage.
- `uptime` — checked uptime and system load.
- `ps -axo pid,comm` — viewed processes and their PIDs.
- `pwd` and `cd` — observed current locations and subfolders.
- `ls -l` — inspected file permissions.

## 5. My understanding
The operating system manages processes, memory, devices, files and permissions. Processes are running programs or services and have unique PIDs. Absolute paths identify a location from the filesystem root, while relative paths use the current location. Permission letters describe allowed actions.
