# Task 3.4 — Operating-system responsibilities

| OS responsibility | My explanation | Example |
|---|---|---|
| Process management | Starts, schedules and stops running programs and system services. | A browser process runs while Terminal continues to receive commands. |
| Memory management | Allocates temporary memory to programs and manages which data can be active. | An open document stays in memory while it is being edited. |
| Device management | Controls communication between software and hardware through drivers and system services. | The OS sends text and graphics to the display. |
| File management | Organizes files and folders, tracks locations and controls access. | Saving `notes.txt` stores it inside `terminal-practice/`. |
| User interface / shell | Provides graphical or command-line ways for users to interact with the computer. | Terminal accepts commands and Finder/desktop displays windows. |
| Security and permissions | Controls accounts, system access and allowed file actions. | The permission `-rw-r--r--` lets the owner read and edit a file. |
