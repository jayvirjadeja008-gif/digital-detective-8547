# Task 1.1 — Trace an activity using IPOS

## Activity: creating and saving this assignment document

| Stage | What happens in this example? | Hardware or component involved |
|---|---|---|
| Input | I type assignment text into a text editor and select a save command. | Keyboard, trackpad or mouse |
| Processing | The operating system receives the keyboard and save events. The editor processes the text and the CPU performs the instructions, while memory holds the active document and program data. | CPU, RAM and macOS |
| Output | The display shows the text and confirms that the file is saved. | Screen/display |
| Storage | The operating system writes the document to persistent storage; Git and GitHub later keep project history and a remote copy. | SSD, Git and GitHub |

## How the stages connect

The text first enters the computer through an input device. The processor and operating system carry out the editor's instructions using temporary memory. The screen provides output so I can review the document. Finally, the operating system stores the file on the SSD, and Git can add it to a version-controlled commit.
