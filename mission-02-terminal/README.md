## 2. Task / objective
Use Terminal commands to inspect directories, manage practice files safely, understand command flags and pipes, and explain package managers.

## 3. Work completed

## 4. Commands / tools used
- `pwd` — showed the current directory.
- `ls`, `ls -l`, `ls -la`, `ls -lh` — displayed directory contents and listing options.
- `cd` — moved between the assignment repository and its parent.
- `mkdir` — created the practice directory.
- `touch` — created an empty practice file.
- `cp` — copied a file.
- `mv` — renamed or moved a file.
- `cat` — displayed file contents.
- `|` and `head -n 5` — filtered listing output.
- `brew --version` and `brew list` — checked package-manager status and package count.

## 5. My understanding
The Terminal uses commands and arguments to perform file operations precisely. Flags modify command behavior, while pipes pass output from one command into another. A package manager simplifies software maintenance.
