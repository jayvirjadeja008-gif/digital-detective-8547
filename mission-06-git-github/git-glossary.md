# Task 6.4 — Git command glossary

- `git init` — creates a new local Git repository.
- `git status` — reports the active branch and the state of working and staged files.
- `git add` — stages selected changes for the next commit.
- `git commit` — records the staged snapshot in local Git history.
- `git log` — displays recent commits and their messages.
- `git branch` — lists branches; `git branch <name>` creates a named branch.
- `git switch` — changes the working files to another branch.
- `git push` — sends local commits to a remote repository.
- `git pull` or `git fetch` — retrieves remote changes; `git pull` fetches and merges or rebases them into the current branch.
