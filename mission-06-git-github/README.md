## 2. Task / objective

## 3. Work completed

- Staged and committed the README change.
- Published the branch and created a Pull Request.

## 4. Commands / tools used
- `git status` — checked repository state.
- `git add README.md` — staged the README update.
- `git commit` — committed the staged update.
- `git log` — viewed commit history.
- `git switch -c update-about` — created and switched to the branch.
- `git push -u origin update-about` — published the branch.
- GitHub Pull Request — proposed merging the branch into `main`.

## 5. My understanding
Staging prepares selected changes for a commit, while committing records a snapshot. A branch isolates development work. A Pull Request provides an online place to review and discuss changes before merging.
